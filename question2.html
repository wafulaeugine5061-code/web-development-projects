Question 2: Identify the Parts

Provided Code Snippet:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Student Portal</title>
</head>
<body>
  <h1>Welcome to Student Portal</h1>
  <p>Your one-stop platform for academic resources.</p>
</body>
</html>

Questions & Answers:

a) What is the purpose of <!DOCTYPE html>?

It tells the web browser to display the page using the latest modern HTML5 standard[cite: 1].

b) What is the difference between the <head> and <body> sections?

  • <head>: Contains hidden metadata, page title, character set, and styling scripts[cite: 1].
  • <body>: Contains all visible page elements like headings, text paragraphs, images, and links[cite: 1].

c) Why is the viewport meta tag important for mobile devices?

It forces the web page to fit the screen size of mobile devices properly, making text readable and responsive without zooming[cite: 1].

d) What would happen if you removed the <title> element?

The browser tab or window header will show the generic file path or file name (e.g., index.html) instead of a readable title[cite: 1].
